# ABC-анализ: стёкла (TopGlass)

Годовой ABC-анализ по стёклам (789 товаров, 8 магазинов), объединённый со скоростью продаж
за последние 3 месяца — чтобы не путать «новинку» с «товаром, который не идёт».

## Как открыть

Просто откройте `index.html` в браузере — это самостоятельная HTML-страница, ничего
устанавливать не нужно.

Если включить в настройках репозитория **GitHub Pages** (Settings → Pages → Source: `main` /
root), страница будет доступна по ссылке вида
`https://<ваш-логин>.github.io/<название-репозитория>/`.

## Что внутри

- **Все** — все 789 товаров.
- **Не проходят** — товары без единой продажи за год.
- **Стоят по-настоящему** — не продаются ни по году, ни за последние 3 месяца (это и есть
  реально зависший товар).
- **Новинки, растут** — слабый годовой ABC (B/C), но хорошая скорость продаж за последние
  3 месяца. Такие товары физически не могли набрать высокий годовой ABC, если появились
  недавно — поэтому их не стоит списывать как «не проходят».
- **Хорошо проходят** — уверенно продающиеся товары.

Разбивка по ABC (A/B/C) — сортировка по выручке за год (метод Парето): A — основной вклад в
выручку, C — наименьший.

Данные заморожены на момент выгрузки (27.09.2026) и не обновляются автоматически.
